## Hợp đồng dùng chung

- Core dùng same-origin `/api`. Portal dùng `VITE_API_ROOT` và `VITE_WS_ROOT` với mặc định `/api`. Axios gắn bearer token từ store và dùng quy tắc refresh/cancel hiện hữu. Các luồng tải tệp, SSO và streaming có đường riêng trong API modules.
- Router duy trì tên route, tham số, role, redirect và lifecycle hủy request. Vue views nghiệp vụ duy trì bộ lọc tenant, payload, response mapping, enum và quyền thao tác.
- So sánh diff với baseline cho toàn bộ `src/api`, `src/router`, `src/stores`, `src/composables`, backend và cấu hình proxy. Đối chiếu request trình duyệt trên một luồng chỉ chứng minh hành vi của luồng đó.
